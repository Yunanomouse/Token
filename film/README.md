# Filming the real app

`dist/venture-trader-film.mp4` is not a recreation. It is the real Venture Trader
dashboard, generated by the app's own code from live market data, served by the
app's own server, and operated with a real mouse and keyboard by a recorder.

## How it works

| File | Role |
|------|------|
| `app_collect.py` | Runs the app's collectors, signal engine and page generator once. No alerts, no brokerage code. |
| `app_serve.py` | Starts the app's own `dashboard_server.py` on `127.0.0.1`. |
| `stage.html` | The film frame: the app in an `<iframe>`, plus cursor, caption bar, and the opening/closing cards. |
| `engine.js` | Camera (pan / zoom / tilt), cursor, captions and scrolling. Targets are selectors resolved against the live page every frame, never fixed pixels. |
| `timeline.js` | The script of the film: clicks, typing, cursor path, camera moves, scroll targets, captions. |
| `record.mjs` | Steps the film one frame at a time, performs the real input, and encodes the frames. |

Three things keep it frame-perfect even though the page is real and interactive:

- **The page's clock is stepped.** JavaScript time advances exactly one video frame
  per screenshot, so timers and the 30-second refresh run at film speed.
- **CSS animations are stepped too.** Marquees, hover fades and the popup's fly-in are
  paused and advanced one frame at a time through the Web Animations API.
- **Data calls take a fixed time on screen.** A ticker lookup is fetched for real, then
  handed to the page a set number of film-milliseconds later, so the "Fetching…" state
  always lasts the same.

Every click names the element it expects under the cursor; the recorder stops with an
error rather than click something else.

The app refuses to be framed (`X-Frame-Options: DENY`). The recorder drops that header
inside its own headless browser only, so the page can sit on the stage. The app is not
modified.

## Run it

```bash
# 1. a throwaway copy of the app, and its pinned dependencies
git -C /path/to/openbb-trader archive HEAD | (mkdir -p /tmp/vt/app && tar -x -C /tmp/vt/app)
python3 -m venv /tmp/vt/env && /tmp/vt/env/bin/pip install -r /tmp/vt/app/requirements.txt

# 2. collect live data and build the dashboard, then serve it
/tmp/vt/env/bin/python film/app_collect.py /tmp/vt/app
/tmp/vt/env/bin/python film/app_serve.py /tmp/vt/app 8090 &

# 3. film it (video + soundtrack + MP4)
bash render/build.sh film
```

Check single moments without a full render:

```bash
node film/record.mjs --shots 12,31.5,48 --shotdir dist/_frames
```

## What is and isn't shown

The film opens only tabs that have data without private keys: Overview, the stock
popup (any-ticker lookup), Watchlist, Markets, Crypto, Signals, Fundamentals, News,
Discover and Insiders. AI Analysis, Options Flow, Calendar and the Macro panels need
the owner's own keys or local model and are not opened.

Prices, signals and headlines are whatever the live feeds returned when
`app_collect.py` ran, so every render shows that day's market.
