QUANTUM STATION - every bot on this computer (new, recommended)
==============================================================

Windows: double-click  Quantum Station.bat   (other systems: python3 station.py)

It runs the $100k and $40 daily bots after each close and the $50 intraday
bot every 5 minutes during the session, with a dashboard in your browser at
http://127.0.0.1:8777/ . Keep the black window open: the bots run only while
it is open and the computer is awake. Paper trading only. Everything it
saves is in the local_data folder. Full guide: docs/station.md

PAPER TRADING - buy and sell by hand with pretend money (new)
============================================================

Windows: install it with "Paper Trading Setup.exe" from
  https://github.com/Yunanomouse/Token/releases/tag/paper-trading-latest
then open Paper Trading from the Start menu or the desktop icon. It is a
normal program with its own window; Python is included.
(From these files instead: double-click Paper Trading.bat.)

Look up a stock and place market, limit or stop orders yourself, with a
balance you choose. It can run alongside Quantum Station. Pretend money
only: no broker is connected. Prices are real but delayed (Yahoo), or
made-up demo prices. Full guide: paper_trading/README.md

QUANTUM TRADING - paper-trading dashboard
=========================================

Needs: Python 3.10 or newer (https://www.python.org/downloads/).
       On Windows, tick "Add python.exe to PATH" in the installer.

To open the program:

  Windows : double-click  Quantum Trading.bat
  macOS   : double-click  quantum_trading.command
            (first time: right-click > Open, because it is unsigned)
  Linux   : run  python3 launch.py  in this folder

A black window opens and stays open (that is the server), then the dashboard
opens in your web browser at http://127.0.0.1:8765/. Close the black window
to stop the program. The first start offers to install numpy, the one
dependency.

If NOTHING happens, or a window flashes and vanishes:
  - You may still be looking inside the zip. Right-click the zip, choose
    "Extract All..." (Windows) or double-click it (Mac), and open the
    extracted folder, not the zip.
  - Python is probably not installed. Install it from python.org (tick
    "Add python.exe to PATH" on Windows), then double-click again.
  - Windows may show "Windows protected your PC": click "More info", then
    "Run anyway". The launcher is a plain text file you can open in Notepad.
  - If the browser does not open by itself, open it yourself and go to
    http://127.0.0.1:8765/  while the black window is open.

Everything is PAPER trading: fills at the close, no slippage, no exchange
connection. The dashboard cannot place real orders.

Try first: leave the defaults, set "Replay speed" to 40, press Start, and
watch it trade eight years of real prices. Then try "Start fresh" with
"Kill switch" at 0.12 and Start date 2007-01-01 to see it halt in 2008.

Command line, if you prefer:   python -m quantum desktop
More:                          README.md and docs/quantum_trading.md
