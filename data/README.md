# Bundled datasets for the `quantum/` package

Everything the package needs to run offline, with where it came from and
under what terms. Nothing here was generated by this repository; each file is
a verbatim copy from the source named.

## `prices/` — real daily prices (MIT)

| File | Contents |
|---|---|
| `us_equities_1989_2018.csv` | Adjusted daily closes for 20 US tickers, 1989-12-29 to 2018-04-11, 7,125 rows. Tickers list at different dates (FB 2012, BABA 2014, GM 2010, MA 2006, GOOG 2004); missing cells are blank. |
| `spy_1993_2018.csv` | SPY adjusted daily closes, 1993-01-29 to 2018-04-11. |

Source: the test resources of [PyPortfolioOpt](https://github.com/robertmartin8/PyPortfolioOpt)
(Robert Andrew Martin, MIT License, `tests/resources/stock_prices.csv` and
`spy_prices.csv`). Originally Yahoo Finance adjusted closes. Citation:
Martin, R. A. (2021). PyPortfolioOpt: portfolio optimization in Python.
*Journal of Open Source Software*, 6(61), 3066.

Use with `quantum.market.load_price_csv(path, tickers=..., start=..., end=...)`.
`load_price_csv` drops any row with a missing value, so pass `tickers=` to
select names with full coverage over the window you want; 17 of the 20 are
complete from 2006-05-25 (all but FB, BABA, GM).

## `qoblib/` — one instance of the Quantum Optimization Benchmarking Library

Problem class 06 (multi-period portfolio), instance `po_a010_t10_orig`: ten
S&P 500 names (AAPL, NVDA, MSFT, GOOG, GOOGL, AMZN, META, TSLA, AVGO, WMT),
ten periods, budget 4, unit copies 3, capital 10 — 710 binary variables.

| Path | Contents | License |
|---|---|---|
| `po_a010_t10_orig/instance/` | `stock_prices.txt.gz`, `covariance_matrices.txt.gz` | CC BY 4.0 |
| `po_a010_t10_orig/qubo/` | Eight `uqo_*.qs.xz` QUBO files, one per risk weight λ ∈ {0, 1e-6, 1e-5, 5e-5, 1e-4, 5e-4, 1e-3, 1e-2} | Apache 2.0 |
| `po_a010_t10_orig/solutions/` | Canonical solutions; `.opt.sol` are Gurobi-proven optima (λ = 0, 1e-6, 1e-5), `.bst.sol` best known | Apache 2.0 |

Source: [ZIB-AOPT/QOBLIB](https://github.com/ZIB-AOPT/QOBLIB), commit
`2b400f43` (2026-08-29). Citation: Koch, T., Bernal Neira, D. E., Chen, Y.,
et al. (2026). The Quantum Optimization Benchmarking Library. *Nature
Computational Science*, 6, 653–671.

Use with `quantum.qoblib` or `python3 -m quantum qoblib`. The file-format
details that matter (symmetric off-diagonal entries, slack-register ordering,
the omitted constant of 1.16 × 10¹⁰) are documented in that module and were
verified against the certified optimum.

## Not bundled, but available from the same sources

- QOBLIB ships 44 portfolio instances up to 400 assets × 15 periods
  (4,666 variables) and nine other problem classes; the full clone is 1.9 GB.
- QOBLIB's instance generator carries raw daily OHLCV for ~500 S&P 500 names
  over January–May 2024 (`misc/instance_generation/stock_data_*.tar.gz`).
- Zenodo hosts IBM calibration snapshots (T1, T2, gate and readout errors,
  coupling maps) alongside error-correction experiment datasets, e.g. records
  18045662 and 20768087; those hosts were not reachable from the environment
  this was assembled in.
